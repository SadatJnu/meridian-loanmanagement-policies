# Meridian Loan Management — public policy pages

Public pages for the **Meridian Loan Management** Android app (package `com.meridian.loan_management`) by
Meridian Softworks, served with GitHub Pages and used in the Google Play Console.

| Page | URL |
|---|---|
| Privacy Policy | https://sadatjnu.github.io/meridian-loanmanagement-policies/privacy-policy.html |
| Delete your account | https://sadatjnu.github.io/meridian-loanmanagement-policies/delete-account.html |

These files are generated in the app's project (`docs/play_store/*.md` -> `python tools/make_play_package.py`,
folder `04_Policy_Pages`). To change a page, replace its `.html` file here; the URLs stay the same.
